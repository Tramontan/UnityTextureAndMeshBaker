# Changelog

## [1.1.0] — 2026-09-26

- **Tools/Создание LOD**: окно следует за выделением — треугольники/вершины, существующие LOD;
  рекомендуемые уровни и пороги по сложности и размеру объекта (редактируются);
  «Создать LOD» / «Удалить LOD» с точным возвратом к исходному. Работает с обычными объектами,
  запечёнными префабами (UV атласа сохраняются точно) и сшитыми секциями.
- Упрощение мешей (QEM, схлопывание рёбер к существующим вершинам): швы UV, жёсткие рёбра и
  границы материалов сохраняются; двусторонний контроль погрешности в пикселях экрана — тонкие
  детали не превращаются в «паруса».
- **Запекание мешей** понимает LOD: объекты с LODGroup сшиваются по уровням в секцию с
  LODGroup (пороги пересчитываются под размер секции); объекты без LOD входят во все уровни.
- **Запекание текстур** не заменяет префабы, пока на их экземплярах есть созданные LOD.

## [1.0.0] — 2026-09-26

Первая версия пакета (перенесено из проекта TestCarsAndLoc).

- **Tools/Запекание текстур**: объединение текстур материалов в атласы, превью раскладки,
  префабы-варианты с перенесёнными UV, замена экземпляров в открытых сценах, конфиг
  `bake_config.json`, распекание с возвратом исходных префабов (в т.ч. в закрытых сценах).
- **Tools/Запекание мешей**: сшивание объектов сцены в секции — сетка полос, зоны вручную
  (многоугольники), секции из выделения; перенос MeshCollider; режимы «вся сцена» /
  «только внутри объектов»; распекание с точным возвратом объектов.
