# Changelog

## [1.2.1] — 2026-09-26

- **Запекание текстур** больше не падает с «Parent directory must exist before creating asset …/Materials/Atlas_1.mat»,
  когда папка результатов уже лежит на диске, но не импортирована в Unity (создана вне Unity или осталась
  при выключенном Auto Refresh). `AssetDatabase.CreateFolder` в таком случае молча создавал рядом
  «<имя> 1», а файлы писались в неимпортированную папку. Теперь такая папка импортируется, имя для новой
  папки запекания выбирается свободным и в AssetDatabase, и на диске, а если Unity всё же создаёт папку не
  там, запекание останавливается с понятной ошибкой без лишней «… 1».
- То же исправление в запекании мешей и создании LOD: все папки создаются через один общий помощник.

## [1.2.0] — 2026-09-26

- **Запекание мешей, «Убрать со сцены»**: исходные объекты теперь полностью удаляются из сцены
  (не грузятся ни в редакторе, ни в билде). Их точная копия — экземпляры префабов со всеми
  override, LOD и т.п. — хранится в префабе `Generated/<сцена>_<id>/Sources/<секция>.prefab`;
  при распекании объекты создаются заново на прежних местах. Файл хранилища удаляется, только
  когда на него не ссылается ни текущая, ни сохранённая версия сцены (откат сцены безопасен).
- Объекты, на которые ссылаются другие объекты сцены (или которые сами ссылаются на объекты
  сцены), не удаляются — у них выключаются рендеры, чтобы ссылки не потерялись.
- Режим «Выделение объектов»: ссылки секции на объекты восстанавливаются после распекания.
- Секции, запечённые прежней версией: кнопка «Удалить исходники со сцены (перенести в хранилище)».
- После распекания у оставленных объектов не остаётся лишнего override `enabled`.
- LOD, созданные на части секции (например, на `Render`), привязываются к секции; распекание
  секции удаляет все LOD внутри неё вместе с мешами.

## [1.1.0] — 2026-09-26

- **Tools/Создание LOD**: окно следует за выделением — треугольники/вершины, существующие LOD;
  рекомендуемые уровни и пороги по сложности и размеру объекта (редактируются);
  «Создать LOD» / «Удалить LOD» с точным возвратом к исходному. Работает с обычными объектами,
  запечёнными префабами (UV атласа сохраняются точно) и сшитыми секциями.
- Упрощение мешей (QEM, схлопывание рёбер к существующим вершинам): швы UV, жёсткие рёбра и
  границы материалов сохраняются; двусторонний контроль погрешности в пикселях экрана — тонкие
  детали не превращаются в «паруса».
- **Запекание мешей** понимает LOD: объекты с LODGroup сшиваются по уровням в секцию с
  LODGroup (пороги пересчитываются под размер секции); объекты без LOD входят во все уровни.
- **Запекание текстур** не заменяет префабы, пока на их экземплярах есть созданные LOD.

## [1.0.0] — 2026-09-26

Первая версия пакета (перенесено из проекта TestCarsAndLoc).

- **Tools/Запекание текстур**: объединение текстур материалов в атласы, превью раскладки,
  префабы-варианты с перенесёнными UV, замена экземпляров в открытых сценах, конфиг
  `bake_config.json`, распекание с возвратом исходных префабов (в т.ч. в закрытых сценах).
- **Tools/Запекание мешей**: сшивание объектов сцены в секции — сетка полос, зоны вручную
  (многоугольники), секции из выделения; перенос MeshCollider; режимы «вся сцена» /
  «только внутри объектов»; распекание с точным возвратом объектов.
