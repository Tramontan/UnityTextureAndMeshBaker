# Changelog

## [1.0.0] — 2026-09-26

Первая версия пакета (перенесено из проекта TestCarsAndLoc).

- **Tools/Запекание текстур**: объединение текстур материалов в атласы, превью раскладки,
  префабы-варианты с перенесёнными UV, замена экземпляров в открытых сценах, конфиг
  `bake_config.json`, распекание с возвратом исходных префабов (в т.ч. в закрытых сценах).
- **Tools/Запекание мешей**: сшивание объектов сцены в секции — сетка полос, зоны вручную
  (многоугольники), секции из выделения; перенос MeshCollider; режимы «вся сцена» /
  «только внутри объектов»; распекание с точным возвратом объектов.
